# PlanRow

Planzeile – ein `Nordhaus.ListItem` mit großer Kennmarke (40 pt), Titel, Beschreibung, Anzahl und Stand; pausiert oder archiviert als `Badge` und in `ink-muted`.

- `category`, `icon`, `title`, `description`, `count`, `updated`, `status` (`paused` · `archived`), `onClick`.
- `PlanItemRow`: Baustein im Plan – Art-Icon, Titel, Zeitplan, Detail, Bearbeiten; Zeile 56 pt (`row-h`) wie das ListItem.
