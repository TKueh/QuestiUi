# Phone

Der Geräterahmen für Screens in Originalgröße (iPhone 15 Pro Max, 430 × 932 pt) mit Statusleiste, Dynamic Island und Home-Indikator – nur für Vorschauen, kein Baustein der App.

- Inhalt scrollt in `.qs-screen-scroll` (hält oben die Safe Area frei); Overlays (`Sheet`, `Dialog`) kommen als letzte Kinder mit `inline`.
- `time` (Statusleiste, Standard 9:41), `homeIndicator`, `style`.
