# ImportPreview

Importvorschau für PDF, Text, Plan-JSON und Apple-Health-XML: Datei, Status-Badge, Kennzahlen (Bausteine, Termine, zu prüfen), Hinweise, Textauszug.

- `file` (ohne: kein Kopf – die Datei steht schon im `FileDrop` darüber), `meta`, `error`, `stats` (`{ label, value }`), `excerpt`, `children` (Hinweise).
