# DocLink

Ein Link oder Dokumentlink: unterstrichener Text mit Datei-Icon und ↗. Die Unterstreichung ist eine Haarlinie in `line-strong` und wird beim Zeigen zu `ink`.

- `variant="chip"` ist die Form für Leisten. Sie hat kein Icon davor, eine 44-pt-Trefferfläche und keinen Rahmen, z. B. „Originalplan ↗“ oben im Detail-Sheet.
- `href`, `external`, `icon` (Name oder `false`; Datei-Zeichen 16 pt, Pfeil ↗ 14 pt), `variant`, `children`. In der Chip-Form erscheint ein Icon nur, wenn `icon` gesetzt ist.
