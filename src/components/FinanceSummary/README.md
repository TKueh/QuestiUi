# FinanceSummary

Finanzübersicht: Monatssumme als Kennzahl, frei verfügbarer Rest, darunter die Gruppen als Messstrecken (`DistributionBars`) mit Betrag.

- `total`, `free`, `label`, `caption`, `rows` (`{ label, amount, tone }`).
- Ausgaben werden gemessen, nicht gewertet: keine Signalrolle, kein `positive`.
