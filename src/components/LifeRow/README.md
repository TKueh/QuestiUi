# LifeRow

Geburtstag-, Wunsch- und Vorhaben-Zeile – ein `Nordhaus.ListItem`: links Datumsfenster (`Badge date`, Geburtstag) oder Kennmarke (Wunsch, Vorhaben), Mitte Titel, Meta und Geschenkidee, rechts gestapelt `BudgetLabel` und `StatusSelect`.

- `kind` (`birthday` · `wish` · `goal`), `date`, `title`, `meta`, `gift`, `amount`, `spent`, `status`, `statusOptions` (mit LED), `action`, `onOpen`.
- Statuswahl und Zeile sind getrennte Bedienelemente – keine Taste in einer Taste.
